RED BALL QUEST — Android Studio Project
=======================================

এটি APK নয়; Android Studio দিয়ে APK build করার সম্পূর্ণ project source।

APK বানানোর নিয়ম:
1. Android Studio ইনস্টল করুন।
2. এই ZIP extract করুন।
3. Android Studio > Open > RedBallQuest ফোল্ডার নির্বাচন করুন।
4. Gradle sync শেষ হতে দিন এবং Android SDK Platform 35 ইনস্টল করুন।
5. Build > Build Bundle(s) / APK(s) > Build APK(s) চাপুন।
6. APK পাবেন: app/build/outputs/apk/debug/app-debug.apk

প্রয়োজন:
- Android Studio
- JDK 17 (Android Studio-র embedded JDK ব্যবহার করা যায়)
- Android SDK Platform 35 ও Build Tools

App package: com.cartoon4vip.redballquest
